# MultiChess

Multiplayer checkmate puzzle race. Host a room, share the 5-letter code (or invite link), and race your friends to find the mate. Pure static site: runs on GitHub Pages with no server.

## How it works
- **Networking:** [PeerJS](https://peerjs.com) WebRTC, browser to browser. The host's browser runs the game; if the host closes the tab, the room ends.
- **Rules:** chess.js validates moves. Mate-in-1: any checkmate counts. Mate-in-2: the key move is unique; the defence is auto-played, then any mate finishes it.
- **Scoring:** 100 / 80 / 60 / 40 for solve order, plus up to 50 speed bonus. Wrong move = 2s lockout.
- **Puzzles:** `puzzles.js`, generated by `tools/gen-puzzles.mjs` and verified by a solver (unique key move, forced mate against every defence).

## Publish on GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save. Site appears at `https://<user>.github.io/multichess/`.

## Run locally
`python3 -m http.server` then open http://localhost:8000 (ES modules need http, not file://).

## Local testing without internet
Run a PeerJS server (`npx peer --port 9000 --host 127.0.0.1`) and add `&peerhost=127.0.0.1:9000` to the URL.

## Regenerate puzzles
```
cd tools && npm i chess.js@1.0.0 && node gen-puzzles.mjs 1 > out.jsonl   # Ctrl+C when you have enough
node build-puzzles.mjs < out.jsonl
```
